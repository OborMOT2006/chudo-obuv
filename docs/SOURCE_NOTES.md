# Источники данных и принятые решения

Проект создан по демонстрационному КИМ 2027, Приложениям 1 и 3, архиву `programming_course-main.zip` с пятью таблицами импорта и изображениями. Преподавательский текстовый пример PyQt5 послужил справочным материалом; программная часть переработана.

- В `Products_import.xlsx` — 31 модель. В `Stock_Items_import.xlsx` встречаются ещё три модели, не присутствующие в Products. Для них созданы записи, но неизвестные `description`, `composition`, `subcategory`, `image_path` оставлены NULL; `category`/`price` восстановлены из `Orders_import.xlsx`.
- В `Sizes_import.xlsx` есть размеры с дробной частью (`36.5`); тип `NUMERIC(4,1)` сохраняет данные точнее, чем `INTEGER`.
- `Users_import.xlsx` содержит опечатку в заголовке «Отчетсво», порядок столбцов позволяет импортировать корректно.
- Исходные `Stock_Items` считаются актуальным доступным остатком. Исторические заказы не вычитаются второй раз при импорте. Создание новых заказов уменьшает склад, отмена/удаление — возвращает соответствующие зарезервированные единицы.
- Все оригинальные фото, логотип и изображение-заглушка сохранены без изменений.
- Файлы аналитики Приложения 4 в присланном материале отсутствуют; поэтому скрипт предусмотрен, но окончательные ответы на задания 5.1–5.6 не вычислены.
- Автотест — отдельный экзаменационный инструмент. Контрольные суммы доступны только при запуске у организаторов.
